# Guia de instalação e uso

## Ambiente com suporte a skills
Instale a pasta `skill-arquiteto-agentes-ia` no diretório de skills da ferramenta utilizada, conforme a documentação desse ambiente.

## GPT personalizado no ChatGPT
No editor de GPTs, incorpore as regras principais do `SKILL.md` no campo de Instruções. Também é possível anexar o arquivo como Conhecimento e orientar explicitamente o GPT a consultá-lo para pedidos de arquitetura de agentes. Um arquivo anexado não se transforma automaticamente em uma skill nativa.

## Exemplos
- Crie a estrutura de um agente de IA em Python e explique cada pasta.
- Audite minha aplicação TypeScript sem alterar a stack.
- Construa um agente com uma ferramenta para consultar horários de cultos.
